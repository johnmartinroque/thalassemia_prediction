# 🫀 Thalassemia Status Predictor

A machine learning project that predicts **Thalassemia Status** from patient clinical data (the classic UCI Heart Disease dataset). It trains multiple classifiers, compares their performance, visualizes the dataset, and serves predictions through an interactive Streamlit web app.

## Overview

Thalassemia is a blood disorder, and in this dataset the `thal` column encodes a patient's thalassemia test result. This project builds a full ML pipeline around predicting that status from other clinical measurements (age, blood pressure, cholesterol, heart rate, etc.), and wraps the result in an easy-to-use UI.

**Thalassemia Status classes:**
| Value | Meaning |
|---|---|
| 0 | Normal / unknown |
| 1 | Normal |
| 2 | Fixed defect |
| 3 | Reversable defect |

## Features

- 🔬 **Multi-model training** — Logistic Regression, Random Forest, SVM, and KNN, trained and compared automatically
- 📊 **Exploratory visualizations** — 7 charts covering class distribution, correlations, and feature relationships
- 🎯 **Accuracy reporting** — per-model accuracy and a detailed classification report for the best model
- 💻 **Command-line predictor** — type in patient values and get predictions from every model
- 🌐 **Streamlit web app** — interactive form-based predictor plus a data insights dashboard

## Getting Started

### Prerequisites

- Python 3.10+
- `heart.csv` — the UCI Heart Disease dataset (with columns `age`, `sex`, `cp`, `trestbps`, `chol`, `fbs`, `restecg`, `thalach`, `exang`, `oldpeak`, `slope`, `ca`, `thal`, `target`), placed in the project root

### Installation

```bash
git clone <your-repo-url>
cd <your-repo-folder>
pip install -r requirements.txt
```

### Usage

Run the steps below in order from the project root.

**1. Train the models**

```bash
python train.py
```

Loads `heart.csv`, removes duplicate rows, splits the data into train/test sets, scales features, and trains four classifiers (Logistic Regression, Random Forest, SVM, KNN). Saves all model artifacts to `models/`, including the exact test split used, so results are reproducible across scripts.

**2. Generate visualizations (optional)**

```bash
python visualize.py
```

Produces exploratory charts from `heart.csv` and saves them to `visuals/`:

| File | Description |
|---|---|
| `01_thal_class_distribution.png` | Class balance across Thalassemia Status |
| `02_correlation_heatmap.png` | Correlation matrix of all numeric features |
| `03_age_distribution.png` | Age distribution, split by Thalassemia Status |
| `04_thalach_by_thal.png` | Max heart rate achieved, by Thalassemia Status |
| `05_chol_by_thal.png` | Serum cholesterol, by Thalassemia Status |
| `06_target_vs_thal.png` | Heart disease diagnosis vs. Thalassemia Status |
| `07_pairwise_scatter.png` | Pairwise relationships between key numeric features |

**3. Check model accuracy**

```bash
python accuracy.py
```

Reloads the saved models and evaluates each one on the same held-out test split used during training, printing a comparison table and a detailed classification report for the top performer.

**4. Predict from the command line**

```bash
python test.py
```

Prompts you to enter a patient's values, then prints predictions (and confidence, where available) from every trained model, plus a final "best model" prediction.

**5. Launch the web app**

```bash
streamlit run app.py
```

Opens an interactive UI with two tabs:
- **🔮 Predict** — fill in patient values in a form and get predictions from all models side by side, plus the best model's result
- **📊 Data Insights** — browse the charts generated by `visualize.py`
